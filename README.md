# 🤖 智能問答助手 (Intelligent Inpatient Service Q&A Assistant)

這是一個完整且功能獨立的**醫療住院服務智能問答助手**網頁系統，100% 還原 `https://e620e620.my.canva.site/` 的視覺設計、色彩配置與交互功能。

---

## 🌟 主要特色與功能

### 1. 💬 聊天模式（使用者前端）
- **歡迎問候與引導**：提供親切的問候語與熱門提問推薦。
- **六大快捷分類**：
  - 📁 **住院前**：手續報到、個人物品準備、病房費用與單雙人房預約、檢查須知。
  - 📁 **住院中**：探病與陪病規定、病房訂餐、免費 Wi-Fi 連線、請假外出規定、床頭呼叫鈴。
  - 📁 **出院**：出院流程與退房時間、用藥諮詢、預約回診掛號、長照與居家護理銜接。
  - 📁 **文件申請**：中英文診斷證明書、醫療收據副本、病歷摘要/檢驗報告/影像光碟、委託代辦。
  - 📁 **服務設施**：超商/餐廳/ATM位置、停車場收費與陪病停車優惠、愛心輪椅借用、洗衣烘衣機。
  - 📁 **服務電話**：總機、住院服務中心、掛號專線、藥物諮詢、急診與申訴電話。
- **智能語意與關鍵字搜尋**：支援分詞加權比對、標籤關聯搜尋與未命中友善推薦。
- **豐富對話卡片**：顯示所屬分類、信心分數（%）、參考來源與標籤 Chips。

### 2. ⚙ 後台管理（管理者端）
- **📚 知識庫管理**：
  - 即時搜尋、類別篩選。
  - ＋ 新增、編輯、刪除知識條目。
  - **匯出 JSON**：一鍵備份全院問答題庫。
  - **匯入 JSON**：支援覆蓋或附加匯入。
  - **整批匯入 Excel / CSV**：支援 `.xlsx`、`.xls`、`.csv` 檔案快速批量建立題目。
  - **本機離線儲存 (LocalStorage)**：資料異動自動持久化保存在瀏覽器中。
- **🏷️ 標籤知識庫**：
  - 依問答條目的 `tags` 欄位自動動態彙整標籤雲。
  - 點擊標籤可直接篩選相關條目。
  - 支援手動重新「同步標籤」。
- **📈 使用統計**：
  - 知識庫總條目、累積提問次數、標籤總數、查詢命中率。
  - 各分類條目分佈視覺化進度條。
  - 近期提問歷史與命中狀態紀錄。

## 🚀 如何開啟與使用

本專案為純前端獨立 Web 應用，**無需安裝額外的後端伺服器或資料庫**，只需使用任何現代瀏覽器（Chrome、Edge、Safari、Firefox）即可直接執行：

1. **直接開啟**：
   - 在本資料夾中找到 `index.html`，直接雙擊滑鼠左鍵，或以瀏覽器拖曳開啟。
2. **切換模式**：
   - 點擊右上角「💬 聊天模式」或「⚙ 後台管理」即可無縫切換。
