🏥 雙和醫院 智慧諮詢服務 - 外網發布與連線上線教學指引
================================================================================

本系統為 100% 純前端靜態架構（HTML5 + CSS3 + JavaScript + JSON 資料庫），
無須任何後端伺服器與資料庫環境，可極速部署到全球任何外網免費主機！

--------------------------------------------------------------------------------
🌟 方法一：30 秒免費發布到外網（最推薦！永久免費、穩定、自帶 HTTPS 與 QR Code）
--------------------------------------------------------------------------------
使用 Netlify Drop（全球最知名免費靜態託管平台）：

1. 打開瀏覽器，前往： https://app.netlify.com/drop
2. 直接將桌面的【智能問答助手-勿刪】資料夾，整包用滑鼠「拖曳」放到該網頁中央。
3. 系統會在 10 秒內自動發布完成，並給您一組專屬的外網公開網址！
   （例如：https://shh-assistant.netlify.app）
4. 您可以將該網址產生 QR Code 印在醫院海報上，或放入 LINE 官方帳號中，
   民眾用手機連 4G/5G 隨時隨地都能直接開啟使用！

--------------------------------------------------------------------------------
🌟 方法二：發布至雙和醫院官方網站伺服器（院內資訊室最標準做法）
--------------------------------------------------------------------------------
若院方希望網址隸屬於醫院官方網域（例如：https://shh.tmu.edu.tw/qa/）：

1. 將本資料夾內的所有檔案（index.html、css 資料夾、js 資料夾、database 資料夾）
   複製至醫院網站伺服器（IIS / Nginx / Apache）的指定目錄。
2. 民眾即可直接透過醫院官方網址連線！

--------------------------------------------------------------------------------
🌟 方法三：同 WiFi / 院內電腦與手機區網測試連線
--------------------------------------------------------------------------------
若要在院內同一台 Wi-Fi 或內部網路中讓手機連線測試：

1. 雙擊執行資料夾中的【🌐啟動本機伺服器(手機與區網連線).bat】。
2. 視窗會顯示您的連線網址（例如：http://10.97.1.178:8080）。
3. 手機連上相同 Wi-Fi 後，在手機瀏覽器輸入該網址即可開啟！
