======================================================================
  📖 如何在 database/ 資料夾中新增與修改問答資料庫說明書
======================================================================

歡迎使用！本資料夾是「智能問答助手」的實體後台資料庫存放區。
您可以透過以下兩種方式自由新增或編輯資料庫內容：

----------------------------------------------------------------------
【方法一：在資料夾中直接複製/編輯 JSON 檔案】
----------------------------------------------------------------------
1. 複製「範例模板_複製我新增資料庫.json」並更名（例如：03_急診就醫指南.json）。
2. 使用 記事本 (Notepad)、VS Code 或任何文字編輯器開啟該檔案。
3. 修改以下欄位：
   - "name": "您的資料庫名稱（例如：🚨 急診服務知識庫）"
   - "description": "您的簡介或歡迎詞"
   - "categories": ["急診檢傷", "就醫流程", "費用說明", "您好/你好"]
   - "items": 裡面填寫您的問題清單，每筆包含：
     - "question": "問題內容？"
     - "answer": "詳細解答內容"
     - "category": "所屬分類（需在上方 categories 清單中）"
     - "tags": ["關鍵字標籤1", "標籤2"]
4. 儲存檔案。
5. 開啟網頁後，點選頂部「📚 資料庫選單」或進入後台「📤 匯入 JSON」即可載入使用！

----------------------------------------------------------------------
【方法二：在網頁後台視覺化新增，並一鍵匯出到本資料夾】
----------------------------------------------------------------------
1. 雙擊開啟網頁（index.html）。
2. 點擊頂部「📚 資料庫選單」選擇「➕ 建立新資料庫」，或點擊「⚙ 後台管理」。
3. 在網頁上直接點選「＋ 新增問答」或「✏️ 編輯」修改內容。
4. 點擊後台的「📥 匯出資料庫」按鈕，將產生的 .json 檔案儲存到本 database/ 資料夾中進行備份！

----------------------------------------------------------------------
【小提示】
• "category" 欄位決定了前台首頁會出現哪些 📁 手風琴分類按鈕。
• 只要在 "categories" 新增分類名稱，首頁就會自動同步出現該分類卡片！
